# Read With Me

A local reading-room prototype for a software testing course. Open `index.html` in a modern browser; no setup is required.

## Demo accounts

- Reader: `reader@readwithme.com` / `chapterone`
- Admin: `admin@readwithme.test` / `libraryadmin`

Reader sign-in opens the reading homepage. Admin sign-in opens the existing dashboard. The reading homepage includes featured titles, categories, search, a sample shelf, reading progress, and a profile section. The twelve distinct cover illustrations are inline SVG and do not use external images.

The login and account data are a front-end demo, not production authentication. Intentional course defects are kept out of the interface and documented in [testing-defects.md](testing-defects.md). For a concise answer sheet, see [testing-answer-guide.md](testing-answer-guide.md). [testing-reference.md](testing-reference.md) is retained as a short pointer to the complete list.
